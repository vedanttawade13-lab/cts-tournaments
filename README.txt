CTS TOURNAMENTS STARTER
Upload index.html to the root of a GitHub repository named cts-tournaments.
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Includes mode filters (Full Map, Survival, 1v1, 2v2, 3v3, 4v4, 6v6), tournament cards, demo sign-up/login form, player join request, organizer QR upload, admin tournament management, editable price per player, and CSV export.

IMPORTANT: This is a front-end demo. Data is saved in the current browser only; it does not sync to other players. Login is not real authentication. Admin is not secure. No Gmail/SMS notification is sent and payment is not verified. For production, connect a secure backend with database rules, protected admin access, authentication, and server-side payment verification. Never store real passwords or private keys in this HTML. A join request/screenshot is not proof of payment.
